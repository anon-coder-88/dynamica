# Generated contract ABIs

`src/contracts.ts` is generated by scripts/export-abi.mjs from actual compiled Hardhat artifacts. Run `npm --prefix chain run build && npm run abi`. The full vault, reserve, factory and development faucet interfaces are exported with literal types. CI verifies that regeneration leaves no diff.

This compiler output is marked generated in .gitattributes and is excluded from GitHub language statistics. First-party SDK/frontend/test source remains eligible under Linguist's own rules. No production deployment is implied by ABI availability.
