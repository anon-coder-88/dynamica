Dynamica test vault

This Robinhood Testnet MVP lets you claim a valueless asset, approve the vault, deposit to receive ERC-4626 shares, and withdraw the asset. It does not trade, earn yield, or run an autonomous strategy.

  1. Connect an EVM wallet and select Robinhood Testnet (chain ID 46630).
  2. Claim dTEST once from the test faucet contract.
  3. Enter an amount. Approve exactly that amount if needed, then deposit.
  4. Enter an amount to withdraw; confirm each wallet request and inspect the transaction receipt.

Only use test assets. The contract is an unaudited demonstration.
