# Security policy

This repository is a locally verified development protocol and has no independent audit or declared production deployment. Do not use valuable assets.

For a vulnerability, use GitHub private vulnerability reporting if the repository enables it. If it is unavailable, request a confidential reporting route from the maintainers without publishing exploit details in an issue. No confidential contact address or response SLA has been supplied; none is invented here.

Include affected revision, impacted function, reproduction/test and the resulting asset or authority impact. Avoid private keys and personal information. See docs/security.md for the current trust model and docs/validation.md for tested boundaries.
